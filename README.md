# 구술평가 연습 (Speech Rehearsal)

어떤 구술평가든 준비할 수 있는 정적 웹사이트입니다. 대본을 올리면 그 언어로 읽어 주고, 읽는 위치를 하이라이트합니다. 서버 없이 브라우저만으로 동작합니다.

- 배포 URL: https://dictation-helper.github.io/dictation_helper/ (GitHub Pages 설정과 첫 배포 완료 후 접속 가능, 배포 확인 필요)

## 현재 기능
1. **대본 올리기**: 붙여넣기, `.txt` / `.md` 업로드, 제목을 붙여 여러 개 저장·불러오기·삭제 (localStorage).
2. **읽어 주기 (TTS)**: 전체 / 문단 / 문장 재생, 일시정지, 정지, 속도, 언어·목소리 선택, 문장·단어 하이라이트, 문장 클릭 반복.
3. **발표 시간 연습**: 스톱워치(시작·일시정지·초기화), 목표 시간(분·초)과 허용 오차(± 초) 입력, 진행 막대, 목표보다 빠름/느림과 허용 범위 안/밖 표시, 분당 단어 수(WPM). 값은 모두 직접 입력하며 기본값이 없습니다. 목표를 비워 두면 스톱워치만 동작합니다.
4. **연습 기록**: 정지 후 "기록 저장"으로 날짜별 기록을 남기고, 목록에서 개별 삭제할 수 있습니다.
5. **녹음과 발음 비교**: 마이크로 녹음하고 다시 듣기, 음성 인식 결과를 대본과 단어 단위로 비교(빠짐·바뀜·추가를 색과 표시로 구분, 일본어·중국어는 글자 단위). 선택한 문장과 내 녹음을 TTS와 번갈아 들을 수 있습니다.
6. **자주 틀리는 단어**: 비교 결과의 빠진·바뀐 단어를 모아 횟수 순으로 보여 주고, 한 단어 듣기와 모아서 반복 연습(TTS)을 지원합니다.
7. **WPM 연결**: 녹음이 있으면 녹음 길이로, 없으면 스톱워치로 WPM을 계산하고 어느 쪽을 썼는지 표시합니다.
8. **외우기 모드**: 가리기 4단계(전체 보기 → 각 문장 첫 단어만 → 키워드만 → 전부 숨김). 가려진 단어는 점선 상자로 표시하고 화면 낭독기에는 "가려진 단어"로 읽힙니다. 문장별 "보기" 버튼으로 잠깐 확인할 수 있고, 가린 채 녹음해도 비교는 항상 원래 대본 전체 기준이며 결과에 사용한 단계를 표시합니다.
   - 키워드는 전체 보기 단계(또는 "보기"로 연 문장)에서 단어를 눌러 고릅니다. 정규화한 단어(대소문자·문장부호 무시)로 대본별 저장하므로 대본을 고쳐도 유지되고, 같은 단어는 모든 위치에서 보입니다. 대본을 삭제하면 그 키워드도 삭제됩니다.
   - 띄어쓰기가 없는 일본어·중국어는 `Intl.Segmenter` 단어 단위로, 지원하지 않는 브라우저에서는 글자 단위로 가립니다.

## 연습 시간과 WPM
- 단어 수는 `Intl.Segmenter`의 단어 단위(`isWordLike`)로 세고, 없으면 공백 기준으로 셉니다. 공백이 없는 일본어·중국어는 Segmenter가 없는 브라우저에서 정확하지 않을 수 있습니다(확인 필요).
- WPM = 단어 수 / (경과 시간(초) / 60). 현재는 스톱워치 시간을 쓰며, 녹음 기능이 생기면 녹음 시간과 연결합니다.
- 스톱워치는 타임스탬프 차이로 계산하므로 탭이 백그라운드여도 어긋나지 않도록 만들었습니다. 실제 브라우저 백그라운드 동작은 확인하지 못했습니다(확인 필요).
- 연습 기록에는 시간의 출처(`durationSource`: 녹음 또는 스톱워치)가 함께 저장됩니다. 이전 기록은 스톱워치로 처리됩니다.
- 녹음과 비교 방법: 대본과 인식된 글을 정규화(대소문자, 문장부호, 전각 문자 무시)한 뒤 LCS로 정렬합니다. 아주 긴 입력은 메모리를 제한하기 위해 대각선 주변만 비교하므로 크게 어긋난 구간은 부정확할 수 있습니다. 번갈아 듣기는 녹음이 한 파일이라 문장별 구간 없이 녹음 전체를 재생한 뒤 선택한 문장을 TTS로 읽습니다.

## 대본 분리 규칙
- 빈 줄 = 문단 구분. 한 줄 안에서는 `Intl.Segmenter`로 문장을 나눕니다(없으면 정규식 대체).
- 줄바꿈도 문장 경계로 취급합니다. 한 문장이 여러 줄로 끊긴 파일은 줄 단위로 읽힙니다.
- 언어 자동 감지는 문자 범위 기반입니다. 라틴 문자는 모두 `en`으로 보므로 영어 외 언어는 드롭다운에서 직접 고르세요.

## 개인정보
- 대본, 설정, 연습 기록은 이 브라우저의 localStorage(`speech-rehearsal:data`)에만 저장되며 외부로 전송하지 않습니다. 다른 기기·브라우저와는 공유되지 않습니다.
- **음성 인식 결과는 참고용이며 실제 평가와 다를 수 있습니다.**
- **크롬의 `SpeechRecognition`은 말한 소리를 구글 서버로 보내 처리합니다.** 다른 브라우저의 처리 방식은 확인하지 못했습니다(확인 필요). 음성 인식은 **기본으로 꺼져 있으며**, 녹음 화면의 체크박스를 직접 켰을 때만 시작합니다(새로고침하면 다시 꺼짐). 꺼져 있으면 음성 인식 객체도 만들지 않으며, 녹음과 다시 듣기만 동작합니다.
- 녹음 파일은 이 탭의 메모리에만 있고 localStorage에 저장하지 않으며 새로고침하면 사라집니다. 녹음과 대본은 음성 인식을 제외하면 어디로도 전송되지 않습니다.
- 자주 틀리는 단어(단어, 횟수, 마지막 날짜, 대본 id)는 localStorage에 저장됩니다. 키워드(대본 id별 단어 목록)도 localStorage에 저장됩니다. 저장 데이터는 `schemaVersion` 4이며 v1~v3 데이터는 열 때 자동 변환됩니다.

## 브라우저 지원
확인하지 않은 항목은 "확인 필요"로 둡니다. 확인하면 이 표를 갱신합니다.

| 기능 | 크롬 (사용자 수동 확인, 2026-11-24; 기기·버전 미기록) | 사파리 | 그 외 (파이어폭스, 엣지, 모바일 브라우저) |
| --- | --- | --- | --- |
| `speechSynthesis` 읽기 | 됨 | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |
| 단어 단위 하이라이트(`onboundary`) | 됨 | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |
| 일시정지/이어서 | 됨 | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |
| 녹음(`MediaRecorder`)과 다시 듣기 | 됨 | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |
| 음성 인식(`SpeechRecognition`)과 대본 단어 비교 | 됨 (크롬은 구글 서버 전송) | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |
| 외우기 모드 | 됨 | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |
| 탭을 가렸을 때 녹음 중단 | 확인 필요 | 미확인 — 지원 대상 아님(사용자 계획 없음) | 확인 필요 |

- 크롬 결과는 사용자가 직접 써 보고 알려 준 내용입니다(자동 테스트가 아님). 데스크톱인지 모바일인지, 어떤 버전인지는 기록하지 않았습니다.
- **음성 인식 결과는 참고용이며 실제 평가와 다를 수 있습니다.** 크롬의 음성 인식은 말한 소리를 구글 서버로 보내 처리합니다.
- 이 앱은 기능 감지(feature detection)를 사용해, 지원되지 않는 기능은 그 기능만 비활성화하고 앱 전체가 멈추지 않게 합니다. 다만 사파리에서의 실제 동작은 확인하지 않았습니다.
- 단어 경계 이벤트가 없는 브라우저에서는 문장 단위 하이라이트로 대체됩니다.
- 자동 확인은 헤드리스 크롬(가짜 음성·가짜 마이크·가짜 음성 인식)에서 앱 동작만 한 것이며, 실제 음성 출력과 인식 정확도의 근거는 위 사용자 확인뿐입니다.

## 개발
```bash
npm install
npm run dev        # 개발 서버
npm run lint && npm run typecheck && npm run test && npm run build
```

`vite.config.ts`의 `base`는 저장소 이름(`dictation_helper`)과 일치해야 합니다.

## 배포
`main`에 push되면 `.github/workflows/deploy.yml`이 빌드해서 GitHub Pages에 배포합니다. 처음 한 번 저장소 Settings → Pages에서 Source를 **GitHub Actions**로 설정해야 합니다.
